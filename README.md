# 🏠 Система контроля температуры на Arduino

Проект системы мониторинга и управления температурой с использованием RTOS, дисплея и веб-интерфейса.

## 📋 Функциональность
- 📊 Измерение температуры с высокой точностью
- 🖥️ Вывод данных на дисплей
- 🌐 Веб-интерфейс для удалённого мониторинга
- 📱 Управление через последовательный интерфейс
- ⚙️ Два рабочих режима с разной логикой
- 🧵 Многозадачность на базе RTOS
